# E2E テスト範囲（MVP 最小）

**位置づけ**  
[REQUIREMENTS.md](./REQUIREMENTS.md) および [ARCHITECTURE.md](./ARCHITECTURE.md) の採用スタック（**Playwright**）に合わせ、**リリース前の最低限**の自動検証範囲を定義する。

**改訂**  

- 2026-04-24: 初版。

---

## 1. 方針

- **本番**ではなく、**予測可能な環境**（`localhost` ＋ テスト用 DB または**モック**）で回す。  
- **Google 本番アカウント**を CI で使わない。`PLAYWRIGHT_GOOGLE` のような**専用テストユーザー**、または **E2E 専用の「バイパス」ログイン**（開発環境のみ有効＋`E2E_SECRET` 等）を導入するか、**手動**スモークのラインに倒す。  
- **MVP 必須**の 4 本は、どちらかが成立すれば可: ① 安定した**モック auth** ＋ ② **実 OAuth** 手動用チェックリスト。

---

## 2. 自動化するシナリオ（MVP 最小 4+1）


| 優先    | シナリオ                                            | 成功条件（要約）                          |
| ----- | ----------------------------------------------- | --------------------------------- |
| A     | ログイン後、**ダッシュボード**（または Inbox へ**遷移**するホーム）が表示される | 未ログインにリダイレクトされない、主要見出しが表示         |
| B     | **Inbox にタスク追加**                                | 1 行メモ or API 経由で、Inbox 一覧に表示      |
| C     | タスクを**別プロジェクトに移動**                              | `projectId` 変更後、Inbox から消え、移動先に出る |
| D     | タスクを**完了**（`status=done` 等）                     | 一覧上で完了扱い（非表示 or ストローク等）           |
| E（任意） | **負荷ビュー**に遷移し、週ブロックが**0 件**でも破綻しない              | 空状態メッセージ or 0 本                   |


---

## 3. 明示的に E2E の外（MVP）

- 本番 **Google 認証**の完全自動（CAPTCHA/2FA/セッション凍結のため）  
- パフォーマンス負荷・セキュリティスキャン（別ツール）
